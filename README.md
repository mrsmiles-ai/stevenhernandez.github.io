# Fades Place

Official website for Fades Place, a private barber studio in Owings Mills, Maryland.

## GitHub Pages setup

1. Create a GitHub repository.
2. Upload or push everything in this folder to the repository's `main` branch.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.

For the address `https://fadesplace.github.io`, the GitHub account must be named
`fadesplace` and the repository must be named `fadesplace.github.io`.

If the GitHub username is different, the site can instead use a project address such
as `https://USERNAME.github.io/fades-place/`.
